## 수정 시험

## 재현과 증거

프로젝트 루트에서 기존 API 가상환경을 사용합니다.

```powershell
.\apps\api\.venv\Scripts\python.exe scripts\verify_complex_validation.py --evidence artifacts/verification/new-complex-check.json
.\apps\api\.venv\Scripts\python.exe scripts\verify_complex_delivery.py --out artifacts/verification/new-complex-delivery
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify.ps1
```

출력 경로는 기존 증거가 없는 새 경로로 지정합니다. `verify_complex_input_excel.ps1`은 설치 Excel에서 원본을 읽기 전용으로 열어 값·수식·차트·표와 원본 해시를 확인하는 **입력 품질 시험**입니다. 제품 실행/PG 시험과 구분합니다.

생성 경로는 `generate_complex_validation_inputs.py --output <새 폴더>` → `generate_complex_validation_workbooks.mjs <새 폴더> <미리보기 폴더>` → `finalize_complex_validation_inputs.py --pack <새 폴더> --evidence <새 증거 폴더>`입니다. XLSX 작성기는 Codex spreadsheet skill의 `@oai/artifact-tool` 런타임을 사용하며 별도 패키지 설치나 앱 의존성 추가는 필요하지 않습니다. 마지막 단계는 앞뒤 공백 텍스트를 실제 Excel이 보존하는 inlineStr로 직렬화합니다. 기존 고정 입력을 덮어쓰거나 실행 결과로 예상 값을 다시 만들지 않습니다. 새로 만든 파일의 해시는 기존 베타 시험권에 자동 등록되지 않습니다.

실제 로컬/베타 화면/다운로드/설치 Excel 검증과 실패·수정 기록은 `docs/delivery-v3_2/reviews/D08.md` 및 `reviews/evidence/D08-complex.json`에 기록합니다. 이번 시험은 최대 파일 크기·모든 한도 조합·동시 접속·공식 결제·상용 운영 전체를 검증하지 않습니다.
