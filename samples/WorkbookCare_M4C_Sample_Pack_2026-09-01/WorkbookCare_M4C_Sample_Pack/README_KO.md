# WorkbookCare M4-C 실무형 샘플 팩

## 구성

- `samples/`: M4-C 교정용 실무형 합성 Excel 파일 10개
- `expected/M4C_예상결과_및_검증가이드.xlsx`: 예상 탐지·정상 예외·수동 판정·성과지표
- `expected/m4c_manifest.json`: Codex/평가 스크립트에서 사용할 수 있는 구조화된 정답표
- `expected/m4c_expected_findings.csv`: 예상 탐지 36건
- `expected/m4c_normal_exceptions.csv`: 정상 예외 36건

## 샘플 설계 원칙

1. 모든 데이터는 합성 데이터입니다.
2. 각 파일은 실제 업무에서 사용할 수 있는 입력·계산·요약 구조를 갖습니다.
3. 이상은 `#REF!` 같은 명시적 오류보다 파일이 정상처럼 보이지만 결과를 왜곡할 수 있는 조용한 수식 이상에 집중했습니다.
4. 각 파일에는 의도적 이상과 정상 예외를 함께 넣었습니다.
5. 이상 위치는 샘플 파일 안에 표시하지 않고 별도 정답표에서만 관리합니다.
6. Finding은 업무 오류 확정이 아니라 사람이 확인할 이상 후보로 평가해야 합니다.

## 권장 검증 순서

1. WorkbookCare M4-B 내부 베타를 활성화합니다.
2. 샘플 파일을 하나씩 업로드하고 기본 무료 진단이 유지되는지 확인합니다.
3. 수식 패턴 정밀검사를 선택 실행합니다.
4. `01_예상탐지` 시트에 실제 탐지 여부를 입력합니다.
5. `02_정상예외` 시트에서 정상 항목이 잘못 경고됐는지 기록합니다.
6. `05_성과지표`에서 Precision, Recall, F1과 파일별 상태를 확인합니다.
7. 반복되는 오탐은 정상 예외·영역 판별·설명 방식 문제로 구분합니다.
8. 반복되는 미탐은 다음 규칙 구현 후보로 기록합니다.

## 실제 탐지 입력 규칙

### 01_예상탐지

- `Y`: 예상 위치가 M4 Finding으로 탐지됨
- `N`: 탐지되지 않음
- `판단불가`: 위치 또는 유형 매칭이 불명확
- `미실행`: 아직 검사하지 않음

### 02_정상예외

- `Y`: 정상 예외가 Finding으로 탐지됨 — False Positive 후보
- `N`: 탐지되지 않음 — 정상
- `판단불가`: 결과 매칭이 불명확

## 핵심 통제 파일

`10_경영대시보드_정상패턴.xlsx`는 의도적 M4 이상이 없는 Clean Control입니다.
M4 Finding이 발생하면 우선 False Positive 가능성을 검토하세요.

## 주의

- 실제 회사 파일, 고객정보, 급여정보, 비밀번호 등 민감정보를 이 팩에 추가하지 마세요.
- 외부 로그나 피드백에는 파일명·시트명·셀값·수식 원문을 기본 저장하지 않는 것이 좋습니다.
- 합성 샘플에서 높은 정확도가 나오더라도 실제 업무 파일의 상용 정확도를 의미하지 않습니다.
- `SUM`과 `SUMIFS` 중 어느 수식이 업무적으로 맞는지는 업무 맥락 없이 확정할 수 없습니다.
