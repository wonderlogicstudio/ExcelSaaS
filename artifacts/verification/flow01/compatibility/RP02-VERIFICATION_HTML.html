전체 요약

전체 지원 수식 6개를 실제 계산했습니다. 원본의 저장된 계산 캐시는 사용하지 않았습니다.

정적 구조 발견: 원본 0건 → 수정본 0건 · 수식 후보: 원본 0건 → 수정본 0건

선택한 업무 기준이 사실인지, 파일 전체가 업무상 정답인지는 보장하지 않습니다. 수정 범위 밖의 내용은 그대로 남습니다.

검증 항목과 범위

  • PASS · 원본 SHA-256 보존
  • PASS · 승인한 셀과 실제 변경 일치
  • PASS · 비대상 내부 파일 보존
  • PASS · 비대상 셀·서식·구조 보존
  • PASS · 계획된 계산 캐시와 타입 일치
  • PASS · 전체 지원 수식 실제 후계산
  • PASS · 계산 오류 없음
  • PASS · 신규 정적 위험 신호 없음
  • PASS · 수식 후보 재검증 완료
  • PASS · 새 수식 후보 없음

Excel 호환성은 지원 합성 파일과 명시된 버전의 재개봉 근거입니다. 고객 파일을 Excel 앱에서 직접 실행했다는 뜻은 아닙니다.
