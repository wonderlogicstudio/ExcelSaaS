# M3 참여자 동의·기록 가이드

## 사전 고지

진행자는 시작 전에 다음을 알린다.

- 이 테스트는 제품 화면 이해를 확인하는 정성적 연구이며, 참여자의 Excel 실력을 평가하지 않는다.
- 실제 회사 파일, 개인정보, 고객 데이터, 파일명은 사용·수집·기록하지 않는다. 합성 파일만 사용한다.
- 참여는 자발적이며, 질문을 건너뛰거나 언제든 중단할 수 있다.
- 관찰 기록은 이름 대신 `U01` 형식의 ID만 쓴다.
- 정밀검증·Approved Repair·결제는 현재 제공 기능이 아니라 테스트에서 오해 가능성을 확인하는 준비 중 항목이다.

## 녹화는 별도 선택

화면·음성 녹화는 필수가 아니다. 녹화 전에는 다음 문구로 별도 동의를 받는다.

“화면과 발언을 나중에 정확히 검토하기 위해 녹화해도 될까요? 녹화하지 않아도 테스트에는 참여할 수 있습니다.”

동의 여부와 범위(화면만 / 화면+음성)는 관찰 양식에 기록한다. 거절하면 녹화 없이 익명 메모만 남긴다.

## 보관·접근·삭제

- 익명 관찰 메모와 점수표는 제품 소유자와 지정 진행자만 접근하는 로컬 연구 폴더에 보관한다. 실제 결과를 이 저장소에 커밋하거나 올리지 않는다.
- 연락처 등 모집 정보는 관찰 메모와 분리하고, 테스트 종료 후 필요한 후속 연락이 끝나면 삭제한다.
- 녹화 원본은 별도 동의가 있을 때만 보관하며, Round 요약을 확정한 뒤 30일 이내 삭제한다. 요약에는 식별 가능한 발언·화면을 넣지 않는다.
- 참여자가 삭제를 요청하면 법적 보관 의무가 없는 한 익명 메모·녹화를 삭제한다.

## 종료 확인

“오늘 자료는 합성 파일만 사용했고, 기록은 익명 ID로만 남깁니다. 테스트 관련 질문이나 기록 삭제 요청은 모집을 안내한 담당자에게 할 수 있습니다.”
