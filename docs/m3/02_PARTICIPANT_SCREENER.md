# M3 참여자 스크리너

## 모집 기준

다음 중 하나 이상에 해당하는 사람을 모집한다.

- 업무에서 중요한 Excel 파일을 만들거나 수정한다.
- 매출, 재고, 비용, 정산, 보고서 등 결과가 중요한 파일을 관리한다.
- 직접 만들지 않더라도 파일을 검토하거나 승인해 전달한다.
- Excel을 어느 정도 능숙하게 쓰며 결과 설명을 비판적으로 읽을 수 있다.

제외 또는 비중 제한 대상은 WorkbookCare 개발 참여자, 모든 기능을 이미 아는 사람, Excel 강의 수강생·전문가만으로 이루어진 표본이다. 지인이라도 호의적 피드백을 주려는 사람만 모집하지 않는다.

## 익명 스크리닝 질문

참여자의 이름·회사·이메일·실제 파일명은 이 양식에 기록하지 않는다. 모집 담당자가 연락 수단을 별도로 보관하더라도 관찰 CSV와 연결하지 않는다.

1. Excel을 업무에서 사용하는 빈도는 무엇입니까? (매일 / 매주 / 월 1회 이상 / 드묾)
2. 가장 가까운 사용 방식은 무엇입니까? (작성·수정 / 관리·검토 / 승인·전달 / 기타)
3. 본인의 Excel 숙련도는 어떻습니까? (초급 / 중급 / 상급)
4. 중요한 파일을 보내거나 사용하기 전에 오류가 걱정된 경험이 있습니까? (예 / 아니오)
5. 테스트는 합성 파일만 쓰며, 실제 회사 파일·개인정보는 사용하지 않는다는 점에 동의합니까? (예 / 아니오)

모집 시 목표 배분: 일반 실무 사용자 4명 내외, 파일 관리·검토/승인 사용자 2명 내외, 상급 Excel 사용자 2명 내외. 실제 구성은 관찰 시트의 `participant_type`, `excel_proficiency`에만 익명으로 기록한다.
