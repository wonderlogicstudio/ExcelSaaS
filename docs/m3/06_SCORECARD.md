# M3 점수표

## 입력 방식

각 참여자·과제별 원자료는 `05_OBSERVATION_TEMPLATE.csv`에 기록한다. 성공은 `성공 / 부분 성공 / 실패` 중 하나로 남기며, 점수표에는 실제 관찰 뒤의 합계만 입력한다. 현재는 참여자 데이터가 없으므로 모든 값이 비어 있다.

| 기준 | Round 2 판정 목표 | 실제 결과 |
|---|---:|---|
| 정밀검증·Approved Repair가 현재 제공 중이 아님을 이해 | 5/5 | 미수집 |
| P0 오해 | 0건 | 미수집 |
| 10~15초 안에 무료 진단 범위를 설명 | 4/5 이상 | 미수집 |
| 검사하지 않은 항목 1개 이상 설명 | 4/5 이상 | 미수집 |
| 먼저 볼 Finding과 위치 찾기 | 4/5 이상 | 미수집 |
| 다음 행동 설명 | 4/5 이상 | 미수집 |
| 대표 Finding의 Excel 확인 가이드 찾기 | 4/5 이상 | 미수집 |
| 재검사 결과가 업무 정확성 보증이 아님을 이해 | 4/5 이상 | 미수집 |
| 비용을 지불할 구체적인 결과물 1개 이상 선택 | 3/5 이상 | 미수집 |

유료가치 선택은 ‘더 많은 경고’가 아니라 정밀검증, 수정 후보, 수정본, 변경 내역, 재검증 중 하나와 연결되어야 한다. 이 값은 시장 수요·결제율·가격의 통계적 증명이 아니다.

## 심각도 기록

| 등급 | 판단 기준 |
|---|---|
| P0 | 검사 범위 또는 자동수정 제공 여부를 잘못 이해해 위험한 의사결정을 할 수 있음 |
| P1 | 핵심 과제를 완료하지 못함 |
| P2 | 완료했지만 상당한 혼란·지연이 있었음 |
| P3 | 개인 선호 또는 경미한 개선 의견 |

두 명 이상에게 같은 P2가 반복되거나 P0/P1이 나오면 우선 검토한다. 개인 한 명의 디자인 취향만으로 변경하지 않는다.
