# M3 진행자 가이드

## 준비

1. 로컬 스택을 시작하고 Scenario A/B/C 파일과 fixture의 scanner/rule-set 버전을 확인한다.
2. `05_OBSERVATION_TEMPLATE.csv`의 새 행에 참여자 ID만 준비한다. 실제 파일명·회사·개인정보를 입력하지 않는다.
3. 녹화를 할 경우 `10_PARTICIPANT_CONSENT_GUIDE.md`의 별도 녹화 동의를 먼저 받는다.
4. 화면을 참여자가 조작하도록 하고, 브라우저 확대·접근성 설정은 평소 환경에 맞춘다.

## 시작 스크립트

“오늘은 WorkbookCare의 화면과 설명을 확인하는 테스트입니다. 실제 회사 파일은 쓰지 않고 합성 파일만 사용합니다. 저는 사용 방법을 설명하지 않을 것이고, 보이는 내용을 말로 생각해 주시면 됩니다. 막히면 그 화면이 왜 그런지 말씀해 주세요. 언제든 중단할 수 있습니다.”

## 진행 원칙

- Task 문구만 읽고, 정답·기능 설명·가격 근거를 먼저 알려주지 않는다.
- 중립적 후속 질문만 쓴다: “지금 무엇을 이해하셨나요?”, “다음에는 무엇을 하시겠어요?”, “그렇게 판단한 근거는 무엇인가요?”, “어려운 표현이 있나요?”
- 다음처럼 유도하지 않는다: “이 버튼이 더 잘 보이지 않나요?”, “정밀검증이 유료라면 구매하시겠죠?”, “위험 점수가 이해되시죠?”
- 막혀도 먼저 기다린 뒤 “어디에서 계속할 수 있을 것 같나요?”라고 묻는다. 도움을 주었다면 `moderator_help`에 기록한다.
- 화면의 준비 중 기능을 지금 제공하는 것처럼 정정하거나 변호하지 않는다. 그 오해 자체를 P0 후보로 기록한다.

## 시간 운영

- 0~2분: 동의 및 think-aloud 안내
- 2~15분: Task 1~6 핵심 과제
- 15~20분: 시간이 남으면 Task 7, 8, 9 순으로 진행
- 종료: “마지막으로, 이 화면에서 가장 불명확했던 점은 무엇인가요?”만 묻고 감사한다.

세션 뒤에는 발언을 해석해 바꾸지 말고 가능한 한 그대로 기록한다. 발견 사항 템플릿에는 실제 세션이 끝난 후에만 입력한다.
