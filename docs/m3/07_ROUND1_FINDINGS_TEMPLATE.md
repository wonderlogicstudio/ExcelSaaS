# Round 1 발견 사항 — 기록 템플릿

상태: 실제 세션 미실시. 이 문서에는 가상의 사용자 반응이나 결과를 입력하지 않는다.

## 세션 정보

| 항목 | 기록 |
|---|---|
| 테스트 일시 | 미기록 |
| 참여자 ID | U01, U02, U03만 사용 |
| 사용 시나리오 / scanner 기준 | 미기록 |
| 녹화 동의 여부 | 미기록 |

## 반복 발견 사항

| ID | 과제 | 심각도 | 관찰 증거·직접 발언 | 발생 참여자 수 | 최소 수정 후보 | 승인 필요 여부 |
|---|---|---|---|---:|---|---|
|  |  |  |  |  |  |  |

## Round 2 전 의사결정

- P0 또는 반복 P1이 있으면 제품 수정안을 별도로 제안하고 제품 소유자의 승인을 기다린다.
- 허용 범위는 카피, 용어, 정보 우선순위, 카드 정렬, 기본 펼침 상태, 경고 위치, CTA 표현, 모바일 레이아웃이다.
- 새 진단·유료·결제·계정·DB·계측 기능은 추가하지 않는다.
- 승인 전에는 Round 2용 제품 코드를 바꾸지 않는다.
