## 실제 고객 동작과 상품 상태

- 무료 진단: 기존 실제 API로 합성 업로드 → 위치·유형/표·근거 확인 → CSV 다운로드 → 직접 재검사.
- 두 자료 비교: 독립 **준비 중** 보고서 상품으로 표시. 비교 보고서 XLSX·비교 검증 HTML,
  수정본 미포함, B는 정답이 아님. 현재 체크아웃에 비교 엔진이 없어 시작/구매 차단.

  필수 3파일이 생성되었다고 표시하지 않으며 범위 확인/구매도 차단. RP01/RP02 readiness 미판정.
- 정밀검증은 검증 활동으로 구분하고 별도 유료 보고서 SKU를 추가하지 않음.
  무료 직접 재검사와 향후 수정 패키지에 포함되는 후검증을 구분함.

  원격 데이터가 미구현 상품을 AVAILABLE/구매 가능으로 선언해도 이 빌드는 구매 경로를 열지 않는다.
