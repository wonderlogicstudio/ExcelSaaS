# Codex 공통 실행 계약

사람이 선택한 Dxx만 승인된다. 명령문이 전달되면 현행 milestone에 그 범위를 연결할 수 있으나 다른 단계/실결제/공개 승인을 만들어서는 안 된다. 현재 AGENTS 보안 경계와 사용자 미커밋 작업을 보존한다.

현재 코드·최신 관련 review·선택 묶음과 계약 최대 두 개부터 읽는다. 아카이브/120개 문서 전체를 매번 다시 읽지 않는다. 완료된 parser/계산/PG/UI/artifact를 재사용한다. 계획/문서만 쓰고 구현 묶음을 완료시키지 않는다.

같은 묶음에서 구현 → 표적시험 → 원인수정 → 재시험 → 관련 통합검증까지 수행한다. unrelated full suite를 매 셀 변경 전후 반복하지 않는다. 회귀 영향이 있으면 필요한 검증은 생략하지 않는다. 정답표·안전기준·waiver는 임의 변경 금지. 스크립트 존재만으로 PASS 금지.

원본 파일 직접 수정·실고객 자료·live PG/환불·가격 확정·새 유료 리소스·클라우드/Access/트래픽 변경·push·배포·사용자 초대는 별도 승인이다. 로컬 합성 수정본 생성과 sandbox adapter 개발은 선택 묶음 범위 안에서 허용된다.

작업 결과는 `reviews/Dxx.md`, `owner_action.md`, `delivery-progress.json` delta에 남긴다. 원 progress/reviews를 초기화하지 않는다. 실제 파일/명령/exit code/증거/미실행을 적고 사람이 할 3~5개의 확인 행동만 제시한다. 검증한 파일만 선별 local commit; 사용자 변경을 같이 stage하거나 reset/clean/rebase/force push하지 않는다. 변경 없으면 빈 commit 금지.

상품 readiness·개발 승인·고객 plan 승인·운영 승인·실제 사용자/결제 증거는 서로 다른 필드다. 일부 상품 완료가 전체 완료를 뜻하지 않는다. 다음 묶음을 추천만 하고 **완료 후 반드시 정지**한다.
