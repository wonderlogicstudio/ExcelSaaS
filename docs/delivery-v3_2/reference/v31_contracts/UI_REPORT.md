# 고객 화면과 새 검토 보고서 계약

## 고객용 이름

내부 명칭은 대사(reconciliation)지만 첫 화면은 **두 파일 비교**로 표시한다. 보조문구: '같은 거래번호를 기준으로 금액 차이와 한쪽 자료에만 있는 항목을 확인합니다. 원본은 바꾸지 않습니다.'

공개 메뉴는 Excel 점검 / 두 파일 비교 / 이용·파일 처리 안내를 중심으로 한다. 맞춤 의뢰는 공급능력 승인 전 실행·구매 메뉴로 내지 않는다. 정밀검증·재검증은 해당 작업 안의 단계로 보여준다. 새 수식 엔진이나 ERP 메뉴를 만들지 않는다.

## 첫 입력과 적합성

화면은 `자료 → 비교 기준 → 가격·범위 → 처리 → 결과`로 연결한다. 뒤로 갈 때 입력 상태를 보존하지만 구매 후 spec 변경은 새 작업이라는 것을 고지한다. 현재 파일A/B 역할과 지원범위를 늘 볼 수 있어야 한다. 모바일에서도 입력 파일 두 역할을 혼동하지 않게 각각 이름과 상태를 보여준다.

1. 두 파일을 올리기 전에 지원형식/값기반/공통 거래번호/동일 금액 기준을 짧게 안내한다.
2. 표·헤더·키·금액 연결에는 본인 원본의 최소 행 preview와 실제 헤더를 제공한다. 추측한 매핑은 사용자 확인을 받는다.
3. 같은 기간/통화/원 단위/금액의미 확인은 기본 체크로 자동 동의시키지 않는다. 각각 무엇을 비교하는지 설명한다.
4. 부분 모호·자료오류는 결제 전 개수와 제외/보류 의미를 알려준다. 비교 불가이면 결과 구매 CTA를 막는다.
5. 구매 시 총액과 과금 단위(고정 spec 1작업), 제공 산출물·다운로드 기한·재시도·실패처리를 보여준다. 가격 미정/기능 미지원/미구매를 동일한 자물쇠로 표현하지 않는다.

## 결과 탐색

기본은 분류별 그룹: 일치 / 금액 차이 / A에만 / B에만 / 중복·모호 / 자료오류. 각 카드에는 **결과 그룹 수와 A/B 원천행 수**를 구분한다. 모호/자료오류가 있으면 상단 완전성 안내를 숨기지 않는다.

그룹 한 번 열기 → 거래 목록 → 선택 거래의 A/B 원천 위치/금액/차이/기준. 시트→열→셀을 각각 여러 겹 아코디언으로 만들지 않는다. 전체 항목 표도 제공해 숙련 사용자가 직접 검색·필터하도록 한다. 필터 전후 count는 분리하고 XLSX 기본 내려받기는 전체 확정 spec 결과다.

넓은 화면에서는 표+상세, 모바일에서는 전체폭 상세+목록으로 돌아가기. 필터·스크롤·키보드 포커스를 복구한다. 원천에 개인정보가 있을 수 있으므로 screenshot/telemetry 자동 수집 금지. 개별 사용자 확인 상태는 비교 판정·합계·가격을 바꾸지 않는다. 그룹 일괄 확인은 행 범위를 명확히하고 undo를 제공할 수 있으나 실제 원본 수정과 분리한다.

## 중요 문구

- `0`: 실제 값 0, `—`: 없는 원천, `확인 불가`: 금액 오류를 구분한다.
- `MATCHED`: 확인한 같은 비교 기준에서 일치. 양쪽의 업무적 정답을 보장하지 않음.
- `ONLY_A`: 선택한 B자료에서 같은 유효 키가 발견되지 않음. 실제 거래 누락 확정 아님.
- `AMOUNT_DIFF`: A−B 차액. 예상값/손실액/미수금으로 이름 바꾸지 않음.
- `AMBIGUOUS`: 중복키 전체 확인 필요. 첫 행을 고르거나 합계를 맞춰서 해결하지 않음.
- 자료가 잘림/timeout/검증 실패면 완성 보고서 다운로드 차단. 처리 진행 중, 결제 확인 중, 원본 만료, 결과 만료, 문의필요를 구분한다.

기존 IF·IFERROR·SUMIF·복합 수식 설명은 현행 기능 범위에서 유지하되 정적 설명과 실제 계산을 구분한다. 이 비교 상품에 사용자 수식 정답/교체안을 억지로 넣지 않는다.

## 새 XLSX 명세

원본 파일을 load/save해 고치는 대신 새 workbook을 만든다. 기본 이름은 `WorkbookCare_검토보고서_<opaque-short-id>.xlsx`. 고객 원본 filename을 서버 경로에 사용하지 않는다.

|시트|내용|
|---|---|
|안내|합성 여부, 원본 미변경, A/B 관측 비교의 한계, spec/engine/profile, 기준/시점, 보관 안내|
|요약|그룹 수/원천행 수/선택·제외·미상, 알려진 금액 보존식, 검증 범위|
|금액차이|키, A금액, B금액, A−B, tolerance, 양쪽 출처|
|한쪽자료|ONLY_A/ONLY_B, 원천 위치, 금액, 반대쪽 없음 표시|
|중복모호|그룹ID, 해당 키의 모든 A/B행, 알려진 금액, 하위 오류. 자동 대사합계 없음|
|자료오류|잘못된 키/금액 원인·각 원천 위치; 반대 정상행도 그룹에 연결|
|일치|1:1 비교된 각 원천과 delta. 오차내 차액도 그대로|
|범위및제외|선택 표·제외행 사유·미선택 설명·mapping/policy version|

빈 분류도 헤더+0건 설명을 유지해 누락 시트처럼 보이지 않게 한다. 긴 한글·선행0·음수·0·공란·텍스트 숫자의 타입을 확인한다. 웹 합계와 파일 합계는 같은 검증된 결과 모델에서 얻는다. 원천 내용 전체를 새 workbook에 복제하지 않는다.

**보고서는 values-only 산출물**이다. 모든 derived delta/summary는 서버의 검증 결과를 값으로 내보내며 Excel 수식을 추가하지 않는다. 입력 텍스트는 literal string cell, URL은 자동 hyperlink로 활성화하지 않는다. 텍스트 `=1+1`을 수식으로 쓰지 않는다. 보고서에는 macro/external links/connections/formula cell이 없어야 한다.

숫자가 Excel 정밀도 범위를 벗어나면 정확한 문자열로 내보내고 표시 정책을 명시한다. 보고서 서식은 사용 가능한 폭·행 높이·숫자형식·고정 헤더·필터를 제공하되 데이터행 병합 금지. 실제 target Excel에서 열기 시험을 출시 게이트로 기록한다.

## 검증과 배포 차단

쓰기 후 다시 열어 시트/행·분류·출처·정확한 금액·타입/금지 요소를 검증하고 성공한 immutable artifact만 READY로 바꾼다. 실패 파일은 비공개 quarantine/정리하고 UI에 안전한 복구/문의 동작을 제공한다. 공개 정적 자산/로그/분석 도구에 paid 결과를 넣지 않는다.

CSV의 quoting만으로 수식삽입을 해결했다고 하지 않는다. typed provenance와 지원 Excel 열기 방식을 정한 안전 정책을 적용하고 위협 문자를 시험한다. 기존 CSV 포맷의 안전 변경은 버전/문구에 기록한다. [S4](../research/TECHNICAL_SOURCES.md#s4)
