# WorkbookCare V3.2 — 결제에서 승인 수정·산출물까지

이 패키지는 기존 프로젝트에 추가하는 **설계·Codex 실행 명령**이다. 제품 코드·실결제·실고객 수정이 이미 완료되었다는 뜻이 아니다. 기존 V3.1을 덮어쓰거나 L01부터 다시 시작하지 않는다.

## 바뀐 핵심

V3.1은 두 파일 대사 보고서를 완성하는 계획이었고, 고객 원본의 승인 기반 수정은 제외했다. 범위를 좁힌 것은 유효했으나 이것을 WorkbookCare 전체의 완성으로 표현하면 원래 `Diagnosis → Approved Repair → Re-validation` 목적을 누락한다. V3.2는 **지원되는 Excel 문제를 확인하고, 사용자가 승인한 변경을 자동 실행한 뒤, 별도 수정본·변경내역·재검증 보고서를 받는 경로**를 핵심 완성 범위로 복원한다.

두 파일 비교는 이미 진행한 독립 상품으로 유지한다. 두 자료가 다르다고 어느 한쪽이 정답이라고 간주하여 자동 수정하지 않는다. 비교 상품을 먼저 공개하려면 별도 상품 범위로 승인하며, 그것을 승인 수정 완성이라고 표시하지 않는다.

|구매한 것|고객이 받는 것|원본을 수정하는가|
|---|---|---|
|무료 진단|기존 위치·근거·직접 확인 방법·CSV·수동 재검사|아니요|
|승인 기반 수정 패키지|**별도 수정본 XLSX + 변경내역 XLSX + 재검증 HTML**, 주문/검증 식별 정보|업로드 원본은 그대로, 승인된 사본만 변경|
|두 파일 비교 보고서|**새 비교 보고서 XLSX + 비교 검증 HTML**|아니요. 수정본 아님|
|맞춤 업무 자동화|별도 계약에서 정한 도구·서식·사용설명·수용시험|기본 판매 OFF. 실제 납품 담당자가 있을 때만|
