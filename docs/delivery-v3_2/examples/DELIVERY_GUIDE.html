같은 결제 화면이어도 받는 결과물은 다릅니다

실제 구매·승인 서버가 없는 설명용 페이지입니다. 버튼으로 실제 고객 파일을 변경하지 않습니다.

승인한 변경의 결과물

가상 매출파일의 C7 형식과 E8 누락 수식을 바꾸는 설명용 산출물입니다. 고객 입력 원본은 변경하지 않습니다.

받는 파일용도
수정본 XLSX 예시승인한 두 변경이 반영된 별도 파일
변경내역 XLSX 예시셀·변경 전후 타입/수식·이유
재검증 보고서 예시검증된 것과 아직 하지 않은 것의 구분

실제 서비스에서는 결제 뒤에도 정확한 계획 승인 전에는 변경하지 않습니다.
