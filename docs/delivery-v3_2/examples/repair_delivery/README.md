# 공개 합성 산출물 예시

이 폴더는 ‘고객이 무엇을 받는가’를 설명하기 위한 예시이며 제품 engine 출력이 아니다. source_DEMO.xlsx는 원본 예시, workbookcare_repaired_DEMO.xlsx는 승인된 변경이 적용된 결과 모양, changes_DEMO.xlsx는 변경 설명, verification_DEMO.html은 검증 범위 표기 예시다.

실제 결제·사용자 변경승인·원자적 package patch·서버 owner 검증·독립 Excel oracle는 실행하지 않았다. 실제 제품은 이들 gate를 통과해야 납품할 수 있다. 샘플 hash와 manifest는 예시 파일이 무엇인지 식별하는 목적이다.
