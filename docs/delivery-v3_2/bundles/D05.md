# D05 — 비교 상품 계승·검토 보고서 완결

## 목표

이미 진행한 두 파일 비교 상품을 보존하며 수정 상품과 혼동되지 않는 완전한 보고서 경로를 유지한다.

범위: 비교 독립 분기

선행: D02

## 먼저 읽을 파일

[공통 계약](../08_CODEX_WORKING_RULES.md)과 현재 AGENTS/milestone/관련 review, 아래 두 문서만 기본으로 읽는다.

- [contracts/COMPARISON_AND_BUSINESS.md](../contracts/COMPARISON_AND_BUSINESS.md)
- [reference/v31_contracts/INPUT_ENGINE.md](../reference/v31_contracts/INPUT_ENGINE.md)

## 구현 지시

1. 기존 L02/L03/L04 비교 파서·정책·엔진·report를 재사용하고 미완료 acceptance만 구현한다. 원래 exact-key KRW 정수 profile 유지.
2. 자료오류/중복/한쪽만/금액차이의 판정 순서와 모든 원천 행 보존·미상 금액 분리를 검증한다.
3. comparison_report.xlsx와 comparison_verification.html을 생성/검증하고 수정본이 아니라는 상품·receipt 문구를 일치시킨다.
4. 같은 비교 재시도·재접속·재다운로드와 다음 기간 새 입력을 구분한다. 수정 상품의 사용권/승인을 공유하지 않는다.
5. B자료를 authoritative로 선언했다는 이유로 자동 패치를 시작하지 않는다. 비교→수정 제안은 미지원 workflow 안내까지만이다.

## 필수 검증

- 보존된 V3.1 baseline oracle/edge cases
- 원천행 총수·타입·금액·source locator와 보고서 일치
- 미지원/중복 키로 허위누락/자동 덮어쓰기 없음
- 비교 권리로 repair download/execute 불가
- zero differences도 유효 report, 수정 완료 문구 없음

## 사용자가 확인할 행동

1. 두 명세의 차이와 중복을 찾는다.
2. 검토용 보고서를 내려받는다.
3. 고객 원본이 바뀌지 않은 것을 확인한다.

## 제외

수수료/N:M 배분·ERP·기준B값 덮어쓰기·새 유료SKU.

## 산출/정지
