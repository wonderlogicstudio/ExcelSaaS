# D07 — 고객 여정·운영·업무 확장 경계 완성

## 목표

서비스가 과장 없이 목적별로 연결되고 운영·개인정보·지원·비용 조건이 준비되게 한다.

범위: 공통

선행: D06

## 먼저 읽을 파일

[공통 계약](../08_CODEX_WORKING_RULES.md)과 현재 AGENTS/milestone/관련 review, 아래 두 문서만 기본으로 읽는다.

- [contracts/SECURITY_OPERATIONS.md](../contracts/SECURITY_OPERATIONS.md)
- [contracts/UX_AND_MENU.md](../contracts/UX_AND_MENU.md)

## 구현 지시

1. 기존 UXR/H3/운영 기능 재사용. 무료·정밀·수정·재검증·자동화 메뉴의 실제 capability와 작업 컨텍스트를 일치시킨다.
2. 모바일 계획검토/취소/파일수령/상태복구, 입력/권한/제한/실패/만료/부분검사의 실제 state 화면을 검증한다.
3. 원본·plan·changes·scratch·결과·결제기록의 TTL와 private 접근을 분리하고 기존 삭제 정책의 영향 delta만 시험한다.
4. 가격/실계약/법률/지원·상담담당/데이터지역/실제 운영 자원은 사람의 결정과 검증근거를 남긴다. 실제 권한 없는 live 호출/배포 금지.
5. 반복 실행은 저장된 정책을 새 입력에 재확인하는 수동 job까지만. 과거 승인을 다음달 원본에 재사용하지 않는다.
6. rollback/kill switch/비용·오류·환불 운영·권리회수·삭제의 기술 rehearsal을 synthetic 환경에서 수행한다.

## 필수 검증

- 로그/피드백 원문 sentinel 미노출, private report에는 필요한 전후값 존재
- TTL/입력 만료 후 복구·늦은 승인 차단
- wrong-owner/refunded/cache/CDN/download/CSRF 부정경로
- desktop/mobile keyboard flow·복귀focus
- 가격/납품/지원문구 실제기능 일치; 상담OFF 수집/판매 없음

## 사용자가 확인할 행동

1. 메뉴별 무엇을 받는지 확인한다.
2. 모바일에서 승인과 다운로드를 완료한다.
3. 파일 보관·환불·지원 조건을 결정한다.

## 제외

무인자동수정·실고객시험/실결제·임의배포·상담 포털 확대.

## 산출/정지

실제 코드·연결된 UI/API/산출물과 검증 근거. `reviews/D07.md`, owner_action, delivery-progress delta. `ENGINEERING_VERIFIED_AWAITING_OWNER`, `REUSED_AWAITING_OWNER`, `PARTIAL`, `BLOCKED` 중 실제 판정. 필수 미실행은 별도 표시. 다음 묶음 자동 실행 금지.
