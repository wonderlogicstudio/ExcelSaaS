## 구현 지시

1. 기존 CF/M6 parser·dependency graph·calc adapter를 우선 재사용한다. 없으면 제한된 evaluator adapter를 격리 환경에 구현하고 버전/함수조합 registry를 만든다.
2. RP01 typed conversion 및 RP02 AST/참조 번역으로 exact patch proposal을 생성한다. 원본은 변경하지 않고 별도 in-memory/scratch evaluation copy에서 계획을 시험한다.
3. 고정된 synthetic policy oracle와 타깃 Excel reference를 함께 검증한다. Excel 실행근거 없으면 해당 체크 NOT_RUN이며 공개 수정 차단; 나머지 구현을 마무리한다.
4. unsupported/time/resource failure와 Excel semantic error를 분리한다. 미지원/실패를 IFERROR의 0으로 처리하지 않는다.
5. 입력·정책·engine·template·선택patch·expected impact를 canonical plan digest로 결합하고, paid-only 상세 projection과 무료 범위요약을 구현한다.
6. 전체 선택 집합을 함께 계산하며 subset 선택마다 예상영향/plan을 다시 만든다. 폼의 기준 확인은 execution 승인으로 사용하지 않는다.

## 필수 검증

- SUM/ROUND 및 IF·AND·ISNUMBER·ROUND 등 검증된 중첩 조합
- 절대/상대/혼합참조; 불연속 targets; 누락 vs 공백
- typed errors/IFERROR(engine failure) 차단
- 선택·입력·engine 변경 시 digest 변경
- 독립 예상값·변경 영향·cache!=calc 분리
- hard timeout/kill/scratch cleanup

## 사용자가 확인할 행동

1. 한 셀의 현재/변경 수식과 기대 영향을 읽는다.
2. 기준을 바꾸면 계획이 다시 만들어지는지 본다.
3. 미지원 조합이 계산 0으로 표시되지 않는지 본다.
