# V3.1에서 이어가는 대응표

기존 L01~L08 ID와 상태를 바꾸지 않는다. V3.2는 새로운 실행 ID D01~D08을 사용하며 원 acceptance를 링크한다. 이름이 바뀌었다고 구현을 다시 만들지 않는다.

|기존|재사용 위치|추가/변경|
|---|---|---|
|L01 진단·탐색·CSV|D01|상품별 결과물/미지원/현재 기능 라벨|
|L02 입력·정책·소유권|D02|한 파일 수정용 적합성/기준수식/원본 snapshot|

|L04 대사 보고서·수령|D04/D05|수정본 + 변경내역 + 후검증 bundle의 새 artifact 타입|

`mapping/TASK_120_V32.json`은 V3.1 각 원 항목을 그대로 담고 별도 v32_delta를 붙인다. 원문·원 판정·원 MD 해시는 보존한다. 수정 경로에 필요한 T062/T066/T068/T071~T085 등의 **제한된 부분을 개발 대상으로 복원**하며 전체 함수·업무별 보정까지 완료시킨 뜻은 아니다.

CF00~06/UXR01~10은 추가 승인 단계로 무조건 재실행하지 않는다. 대응표의 D묶음 안에서 필요한 계약을 사용한다. 완료 증거는 코드·설정·의존성·프로필이 같은 경우 재사용한다. 전체 120개가 완료되었다고 선언하지 않는다.

원격 Git은 47e5e54를 읽기 전용 확인했다. 최신 로컬이 앞서면 로컬 변경을 보존한다. H3의 과거 상태 차이는 자동 재검증/재배포 승인이 아니다.
